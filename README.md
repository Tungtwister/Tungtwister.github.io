# Austin Tung — Portfolio

A Windows XP-themed portfolio website built in React. Features a working window manager, boot screen, login screen, taskbar, Start Menu, and multiple app windows — each representing a different section of the portfolio.

Live at: [tungtwister.github.io](http://Tungtwister.github.io/)

## Inspiration

Concept inspired by [Paul Jaguin's OS-style portfolio](https://pauljaguin.com/office).

## Built With

- **React** — UI framework
- **react-rnd** — draggable and resizable windows
- **Create React App** — project scaffolding
- **GitHub Pages** — hosting
- **Claude Code** — AI-assisted development

## Running Locally

```bash
git clone https://github.com/Tungtwister/Tungtwister.github.io.git
cd Tungtwister.github.io
npm install
npm start
```
